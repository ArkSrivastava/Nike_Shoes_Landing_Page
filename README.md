# Nike_Shoes_Landing_Page

A modern, interactive landing page for Nike shoes featuring 3D effects, smooth animations, and a responsive design.

## Features

- 3D product card animations
- Smooth scroll transitions
- Interactive featured product slider
- Dynamic product search
- Shopping cart functionality
- Responsive navigation with dropdowns
- Category-based product filtering
- Wishlist feature (coming soon)

## Tech Stack

- HTML5
- CSS3 (with modern features like CSS Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- CSS Custom Properties for theming

## Key Components

1. **Hero Section**
   - Full-screen layout
   - Animated text elements
   - CTA button with 3D effect

2. **Featured Slider**
   - Scroll-based transitions
   - 3D perspective animations
   - Auto-sliding functionality
   - Navigation controls

3. **Product Grid**
   - Interactive 3D card effects
   - Smooth hover animations
   - Add to cart functionality
   - Dynamic price formatting

4. **Search Function**
   - Real-time search results
   - Debounced input handling
   - Highlighted search matches

## Setup Instructions

1. Clone the repository:
   ```bash
   https://github.com/ArkSrivastava/Nike_Shoes_Landing_Page.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Nike_Shoes_website
   ```

3. Open index.html in a modern web browser
   - For local development, use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx serve
   ```
